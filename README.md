# LunaBloom · 小账本

以「海月藏宝」为主屏幕图标的 iPhone 轻量记账工具。

## 发布
GitHub Pages 发布源设置为 `main` 分支、`/(root)` 目录。

## 功能
- 一张微信或支付宝账单截图识别多笔收入/支出
- 自动提取金额、日期、时间和交易名称，识别后逐笔人工确认
- 分类推荐、事项补充、手动新增、编辑和删除
- 月度/年度/全部支出统计与分类饼图
- JSON 备份恢复、CSV 导出
- PWA 主屏幕入口和基础离线缓存

## 数据与隐私
账本记录保存在当前浏览器的本地存储中，不会自动同步到其他设备。OCR 在浏览器本地执行；首次使用需联网加载 Tesseract.js 与中文识别模型。请定期导出 JSON 备份。
